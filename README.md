# Odin Recipes

A simple recipe website built with HTML.

## Description

This project is a basic recipe website created as part of The Odin Project Foundations course.

It contains three recipes:
- Lasagna
- Pizza
- Couscous

## Skills Demonstrated

- HTML boilerplate
- Working with headings and paragraphs
- Creating ordered and unordered lists
- Adding images with alt attributes
- Creating links between pages
- Using relative file paths
- Organizing files and folders
